# Commit Title

feat: 커뮤니티 캔버스 피드를 자유 배치로 구성한다

# Changed File Scope

메인 explore 기능의 예시 데이터·카드·CSS·한국어/영어 문구, 관련 브라우저 검사와 캔버스 개발 문서.

# Reason

사용자가 제시한 주목/추천/떠오르는 캔버스/이야기 콘텐츠 형식을 메인에 적용한다. 행·열에 맞춘 목록 대신 유한 캔버스의 자유 배치를 사용하고 사람을 따르는 영역은 관심 있는 사람들의 캔버스로 표시한다.

# Design

최종 네 영역은 주목·추천·떠오르는·관심 있는 사람들의 캔버스다. 큰 브랜드와 주목 이미지를 중심으로 사진을 가까이 묶되 높이와 시작점에 변화를 준다. 작성자·댓글·좋아요는 사진 오른쪽 아래 한 묶음으로 표시한다. 배치는 새로고침/언어/카메라 이동 때 다시 계산하지 않는 안정된 좌표를 사용한다. world는 3200×2100으로 넓히고 초기 콘텐츠 보기와 구분한다. 기존 minimal 셸·25~200% 줌·Space 이동·미니맵은 유지하고 사이드 관심사 찾기 버튼만 제거한다. 화면의 예시 안내는 사용자 지시에 따라 제거하되 개발 문서에는 고정 샘플이며 실제 API와 연결되지 않았음을 기록한다.

공통 카메라의 논리 좌표는 유한 경계 안에 두고 시각적 저항만 최대 10px 이내로 적용한다. 입력과 복귀 모두 시간 기반 보간을 사용하며 모션 감소에서는 생략한다. 미니맵은 논리 좌표를 따른다. 입력 종료·Space 해제·새 focus/fit/zoom·언마운트 시 저항과 타이머를 정리한다.

# Verification Plan

검색·선택·축소 중 문구·카메라 입력 회귀와 자유 배치·작성자/메타데이터·샘플 표시를 브라우저에서 확인한다. 라이트/다크와 320/390/1440px 실제 화면을 확인한다. make verify-plan → make verify 및 푸시 훅, 실제 PR 메타데이터 검사 후 merge commit으로 병합한다.

# Impact

메인의 정적 커뮤니티 예시 콘텐츠만 변경한다. 공통 인증/결제/설정·카메라 규칙과 저장형 캔버스 도메인은 보존한다.

# Loop Alignment

공용 Button/Tooltip과 기존 UI 상태·카메라/미니맵 생명주기를 재사용한다. 정적 예시이므로 새로운 API·실시간 구독·저장 루프는 없다.

# Verification

make verify-plan 및 make verify 통과: 15개 명령, 161.6초. 백엔드 504개, 프런트 단위 205개와 전체 UI·운영·스타일·계약·초기화 검사를 통과했다. 라이트/다크 320/390/1440px 화면을 확인했고 git diff --check를 통과했다. 푸시 훅과 실제 PR 메타데이터 검사를 추가로 적용한다.

# State Ownership

페이지가 검색·선택 상태를 소유하고 정적 피드 데이터가 예시 작성자·반응과 그룹의 의미를 소유한다. 위치는 기능 CSS, 카메라는 기존 공통 훅이 소유한다.

# Memoization

주제 그룹의 기존 memo와 안정적 선택 콜백을 유지한다. 팬/줌에 따라 예시 데이터를 재생성하거나 미니맵 PNG를 매번 캡처하지 않는다.

# Performance Evidence

카메라 이동 중 스냅샷 URL 유지와 실제 줌·검색 상호작용을 확인한다. 새 라이브러리를 추가하지 않고 같은 출처의 기존 WebP를 재사용한다.
