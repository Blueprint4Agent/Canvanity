# Changed File Scope

공용 Button·Showcase, 메인 캔버스 액션, 설정·관리자 셸과 섹션 내비게이션, 공용 ToastCard와 관련 문서·검사.

# Reason

카드·캡슐과 서로 다른 호버를 줄이고 Canvanity의 여백·격자·푸른 강조를 설정과 관리자에도 일관되게 적용한다.

# Design

기존 Button을 canvas/canvas-card 변형으로 확장하고 실제 Showcase 상태를 기준으로 사용한다. 사진은 작은 확대, 일반 버튼과 드롭다운은 기존 곡률(캡슐 포함)·0.5px 푸른 테두리·연한 파란 표면·안쪽 하이라이트 및 파란 호버 배경, 키보드는 중립 포커스를 사용한다. 설정·관리자 제목은 산세리프, 이미지 캡션만 Settings/Admin 필기체다. 왼쪽 메뉴 위에 조명/작업 공간 이미지를 구분해 배치하고 본문 스크롤과 독립적인 sticky 메뉴를 사용한다. 메뉴에는 공용 색연필 SVG 질감을 적용한다. 우측 본문은 적정 너비로 가운데 정렬하고 행·결제 정보는 얇은 구분선과 좌우 정렬을 사용한다. 모바일에서는 가로 메뉴로 제공한다. 공용 토스트는 6px 모서리와 종이색/차콜 표면·파란 강조선으로 실제 앱과 Showcase에 함께 적용한다. 인증·보안·결제·삭제의 실제 상태와 확인 절차는 유지한다.

# Page Family

## Family

설정·목록/관리자와 메인 UI 캔버스의 공용 액션.

## Reference

현재 계정·일반·결제 설정, 관리자 목록/서버 상태, Showcase Button과 사용자 Minimal Canvas 이미지를 비교한다.

## Shared Rules

동일한 셸·Button·행·헤더·테마 토큰을 사용한다. 액션 상태는 Showcase와 실제 화면에서 일치한다.

## Exceptions

설정과 관리자는 고정 정렬 레이아웃이며 팬/줌을 추가하지 않는다. 보안 확인 모달은 기존 모달 계열을 유지한다.
