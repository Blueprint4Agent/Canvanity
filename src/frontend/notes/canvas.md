# 공통 캔버스 조작 규칙

`src/canvas/canvasRules.ts`가 규칙의 기준이다. `CanvasSurface.kind`는 UI 메뉴(`ui`)와 저장형 게시물(`document`)을 구분한다. 두 종류 모두 유한하고 양수인 너비/높이를 반드시 전달한다. 무한 확장은 지원하지 않는다. UI 메뉴의 현재 범위는 `exploreTopics.ts`가 소유하는 3200×2100이며 게시물의 크기는 향후 문서 도메인이 소유한다. 메뉴 위치를 게시물 문서에 저장하지 않는다.

`useCanvasCamera`가 드래그·휠·터치·키보드 이동·미니맵·fit을 처리한다. 모든 입력은 같은 경계 보정을 거친다. 확대율은 25~200%, 1회 배율은 1.2다. 화면보다 작은 장면은 중앙에 놓고 큰 장면은 끝을 넘어 이동하지 못한다. 배경 격자는 화면 전체를 채우는 시각적 배경이며 이동 가능 영역을 늘리지 않는다. 화면 크기가 바뀌면 초기 보기로 재배치한다.

`useCanvasShortcuts`는 공통 action을 호출하고 각 surface가 선택/검색의 실제 동작을 연결한다. `V` 선택, `/` 검색, `+`/`=` 확대, `-` 축소, `0` 전체 보기다. 마우스는 기본 클릭/선택이며 `useCanvasPanMode`가 Space를 누르는 동안만 임시 이동을 허용한다. Space 해제·창 blur·탭 비활성화 시 즉시 선택 상태로 돌아오고 진행 중 드래그도 종료한다. 이동 아이콘은 현재 Space 상태와 툴팁을 표시하며 클릭으로 이동 모드를 고정하지 않는다. 입력창·편집 가능 요소·IME·열린 다이얼로그에서는 Space를 가로채지 않는다. 활성 캔버스에서는 Ctrl/Cmd + +,-,0도 같은 action에 연결하고 브라우저 기본 확대를 막는다. 다른 조합과 입력/모달은 가로채지 않는다. 일반 휠과 두 손가락 스크롤은 이동, Ctrl/Cmd/Alt+휠과 트랙패드 pinch는 캔버스 확대·축소다. Safari gesture 이벤트와 Ctrl+wheel의 중복 반영을 방지한다. 터치 pinch는 해당 viewport에서만 처리한다. 캔버스 텍스트 선택과 기본 이미지 drag를 막되 검색 입력창의 텍스트 편집은 유지한다. 도구 툴팁은 공통 단축키 상수를 참조한다.

`useCanvasSnapshot`은 DOM 장면 전체를 html-to-image로 캡처한다. 화면 이동마다 다시 캡처하지 않고 내용 버전·언어·테마 변경 시 갱신한다. 미니맵은 실제 이미지와 별도 viewport 테두리를 조합하며 클릭/드래그로 카메라를 이동한다. 실패하면 재시도를 제공하고 이전 이미지를 유지한다. 원격 이미지를 도입할 때는 CORS/오리진을 검증해야 하며 향후 실제 canvas 엔진은 같은 캡처 경계에 엔진 export를 연결한다.

카메라 ref와 requestAnimationFrame은 고빈도 좌표의 소유자이며 React는 줌 표시·검색·선택·도구 상태를 소유한다. transform, world 크기, 격자 위치/간격과 미니맵 테두리의 style 변경은 측정된 기하에 한정된 예외다. 외형은 app.css에서 관리한다. 언마운트 시 프레임·포인터·관찰자·이벤트·비동기 캡처를 정리한다. 현재 화면은 정적 예시 메뉴이며 게시물 CRUD·저장·협업 구현을 뜻하지 않는다.

확대·축소/fit/focus는 카메라 목표값과 렌더된 값을 분리해 requestAnimationFrame의 시간 기반 보간으로 전환한다. 드래그는 직접 반영하며 기존 애니메이션을 중단한다. prefers-reduced-motion은 보간을 끈다. 공용 필기체는 --font-handwriting(Caveat/Nanum Pen Script), 라이트/다크는 종이색·차콜 표면과 브랜드 파란색을 조합한다.

콘텐츠는 넓어진 world 안에 안정된 자유 좌표로 배치한다. 최초 진입은 콘텐츠 범위를 기준으로 하고 전체 보기는 유한 world를 기준으로 배율을 계산하되 25% 하한을 우선한다. 작은 화면에서 world가 한 화면에 들어오지 않으면 이동과 미니맵으로 나머지 범위를 탐색한다. 미니맵과 줌 컨트롤·네브바는 캡슐/외곽 장식 없이 제공하고 줌 컨트롤은 세로로 둔다. 전체 world가 보이면 중복되는 미니맵 viewport 테두리를 숨긴다. 주제 호버는 밑줄 대신 180ms scale이며 모션 감소 설정에서는 전환을 생략한다.

기존 계정 단축키 식별자 toggleSidebar는 저장 호환성을 위해 유지하지만 minimal 셸에서는 프로필 메뉴 열기/닫기로 연결하고 UI에 메뉴 단축키로 표시한다. 프로필 툴팁과 aria-keyshortcuts는 저장된 실제 조합을 사용한다.

축소해도 사진·제목·필기체 문구를 숨기거나 단계별 글자 크기를 적용하지 않는다. 모든 요소가 같은 배율로 자연스럽게 변한다. 설정 화면과 프로필 메뉴는 작은 글자·행 높이·여백을 공유한다.

## 커뮤니티 피드

메인은 브랜드와 큰 주목 이미지를 중심으로 추천·관심 있는 사람·떠오르는 캔버스의 사진 묶음을 가까이 배치한다. 행열 목록이나 실행마다 바뀌는 난수 좌표를 사용하지 않는다. 작성자·댓글·좋아요 수는 고정 샘플이며 실제 추천·팔로우·게시물 API와 연결되지 않았다. 사용자의 디자인 지시에 따라 화면에는 예시 안내를 표시하지 않는다.

경계에 닿으면 논리 카메라 좌표를 유지하면서 화면만 최대 10px 이내로 저항을 표현한다. 입력이 끝나면 짧고 부드럽게 복귀하며 모션 감소에서는 생략한다. 미니맵은 논리 좌표를 따르고 focus/fit/zoom·Space 해제·언마운트에 저항 상태와 타이머를 정리한다. 사이드의 관심사 찾기 버튼은 제거하되 / 검색 단축키는 유지한다.
