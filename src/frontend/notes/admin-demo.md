# 관리자 데모

백엔드 런타임 `DEMO_ENABLED`가 `/config`의 `demo_enabled`를 제어합니다. 값이 없으면 비활성화하며 운영·개발 모드에서 동일하게 동작합니다. 방문자는 `/demo/admin`, `/demo/admin/server`에서 기존 관리자 페이지·테이블·상태 카드를 그대로 사용합니다. 익명화된 실제 사용자 데이터와 서버 상태는 조회 전용 데모 API에서만 가져옵니다. 실제 관리자 경로의 역할 검사는 유지합니다.

필터·페이지 상태는 로컬에서 관리하고 데이터 출처와 사용자별로 요청 스냅샷을 구분하며 이동 시 취소합니다. 기존 테이블 메모이제이션, 데스크톱 연결 복구, 상태 새로고침을 재사용합니다. 비활성화하면 진입 메뉴와 직접 경로를 닫고 백엔드도 404를 반환합니다. 새 전역 상태·가상 계정·쓰기 권한·옵저버빌리티 서비스를 추가하지 않습니다.

프로필 드롭다운의 **관리자 패널 (데모)**로 진입합니다. 실제 관리자의 **관리자 패널** 항목은 별도로 유지하며, 메인 사이드바에는 데모 진입 항목을 중복 표시하지 않습니다.
