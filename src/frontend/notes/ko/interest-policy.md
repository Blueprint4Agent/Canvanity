# 관심사와 태그 정책

Interest는 플랫폼이 관리하는 공식 분류이며 Tag는 이후 콘텐츠에서 사용자가 자유롭게 만드는 세부 키워드다. 두 개념을 같은 목록이나 생성 흐름으로 합치지 않는다.

## 현재 구현

- 프로필: 공식 관심사 최대 8개. `관심사 추가` → 공식 목록 검색·선택 → 저장.
- 검색: 한국어·영어 이름, 고정 ID와 동의어를 검색한다. 예를 들어 `인공지능`으로 `AI`를 찾는다.
- 저장: 표시 이름 대신 고정 ID를 저장한다. 같은 항목을 중복 선택하지 않는다.
- 삭제: 프로필의 관심사 칩 ×로 선택을 제거한다. 공식 항목 자체를 삭제하지 않는다.
- 신규 생성·제안·개인 관심사: 일반 사용자 UI/API에서 제공하지 않는다.
- 관리자: `/api/v1/interests/admin`의 조회·생성 및 `/{interest_id}`의 수정 API를 사용한다. 일반 사용자와 매니저에게 쓰기 권한을 부여하지 않는다. 이름·동의어·노출 순서·활성 여부를 관리하며 고정 ID는 수정하지 않는다. 별도 관리 화면은 아직 없다.
- 비활성화: 공개 목록과 프로필 응답에서 제외하고 새 선택을 거절한다. 기존 연결은 데이터베이스에 보존한다.

`interests`, `interest_aliases`, `user_interests`가 공식 사전·동의어·개인 선택을 분리한다. 0022 마이그레이션은 기존 문자열 중 공식 이름/동의어와 일치하는 항목만 연결하며 기존 JSON 값은 롤백 기록으로 보존한다. 0023은 관심사를 40개로 확장하고 생활·취미부터 보여주는 노출 순서를 추가한다. PostgreSQL의 ID 시퀀스도 초기 데이터 이후로 맞춘다.

## 초기 공식 사전

- 취미·문화: 게임, 음악, 영화, 만화·애니, 사진, 독서, 미술, 공예, 글쓰기, 디자인.
- 일상·라이프: 일상, 여행, 반려동물, 패션, 뷰티, 리빙, 요리, 커피·차, 식물·가드닝, 육아·가족, 연애·관계.
- 운동·아웃도어: 스포츠, 운동, 러닝, 자전거, 아웃도어, 캠핑, 자연.
- 생활·지식·일: 과학, 교육, 경제·재테크, 창업, 자동차, 건축, 생산성, 기술, 개발, AI, UI·UX, 게임 개발.

위 묶음은 구성 설명이며 추천 점수나 실제 이용자 선호도 순위를 의미하지 않는다. UI 순서는 DB의 `sort_order`가 소유한다. 프런트엔드에 공식 목록을 중복 하드코딩하지 않는다.

## 후속 콘텐츠 기능의 기준

- Board: 같은 공식 사전에서 1~3개를 연결한다. `board_interests`는 실제 Board 도메인 개발 시 추가한다.
- Canvas·Board Tag: 사용자가 기존 태그를 검색하거나 새 태그를 생성한다. `tags`, `canvas_tags`, `board_tags`는 해당 콘텐츠 개발 시 추가한다. Canvas의 기준은 최대 10개다.
- 자유 태그는 대소문자·공백·길이를 정규화해 같은 레코드를 재사용하고 관리자 제재를 별도로 적용한다.

이번 작업에는 보드 생성·공유·태그 생성·추천 엔진을 포함하지 않는다.
