# 컴포넌트 점검

공용 UI export와 레이아웃·인증·API 키 구성을 점검했습니다. 유지한 공용 UI는 실제 렌더링 예시를 가지며 TypeScript 심볼 기준으로 자동 확인합니다.

## 정리 결과

- ToastCard는 짧은 문구가 자동으로 사라지는 캡슐이며 데이터·피드백의 ToastPreview에서 확인합니다. 샘플은 API 없이 현재 토스트 하나를 교체·재생합니다.

- SelectionCard를 제어형 공용 선택 버튼으로 분리하여 카탈로그 분류에 재사용합니다. 카드 분류에서 검색 가능한 선택·미선택·비활성 예제를 제공하며 키보드 동작과 테마 대비를 브라우저로 검증합니다.

- 사용하지 않는 ThemeToggle 상태 래퍼를 삭제했습니다. 이전 요청에 따라 ThemeToggleButton은 쇼케이스 전용 선택지로 유지합니다.
- 쇼케이스에만 있던 OAuthOptionsCard는 PanelCard/PrimaryCard와 역할이 겹쳐 컴포넌트와 전용 CSS를 삭제했습니다.
- MenuList는 선택형 메뉴, KeyValueCard는 컴팩트한 설명 목록으로 유지합니다. 의미가 다른 라우팅 메뉴나 프로필 화면에 억지로 대입하지 않습니다.
- OAuthProviderIcon으로 로그인 버튼·연결 계정의 로고 렌더링을 통합했습니다.
- 사진 삭제는 공용 Button을 사용합니다. 파일 선택 label·탐색 링크·스위치·팝업 행은 역할에 맞는 기본 요소를 유지합니다.
- 누락된 PrimaryCard·UserAvatar·AvatarUploadField·CopyField·연결 계정·API 키 미리보기를 추가했습니다. BrandBanner는 별도로 검색되며 StatusCard와 상태별 래퍼도 표시합니다.
- API 키 예시는 실제 기능 컴포넌트에 로컬 샘플 상태만 전달합니다. OAuth는 인증 미리보기를 열고, 최근 계정·업로드는 실제 기록이나 프로필을 변경하지 않습니다.
- 문구를 번역하고 분류·검색을 추가했습니다. 쓰지 않는 카탈로그 그룹 CSS를 정리하고 키/값 표시를 컴팩트하게 조정했습니다. 단순 문자열 검색만으로 관련 없는 CSS를 대량 삭제하지 않습니다.
