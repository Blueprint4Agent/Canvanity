# 둘러보기 예시 사진

사진은 Unsplash에서 내려받아 같은 출처의 정적 WebP로 제공한다. 브라우저·미니맵이 외부 이미지 서버에 요청하지 않는다. 라이선스: https://unsplash.com/license (확인: 2026-10-24). 커뮤니티 게시물이 아닌 메뉴 분위기를 위한 예시 이미지다.

필기체는 Google Fonts의 Caveat와 Nanum Pen Script를 로컬 제공한다. 폰트 라이선스는 public/fonts의 각 OFL.txt에 포함한다. 영문 로고/캡션은 Caveat를, 한글 필기체가 필요한 곳은 Nanum Pen Script를 사용한다.
